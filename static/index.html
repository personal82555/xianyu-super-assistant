仪表盘

仪表盘是系统的概览首页，展示系统运行的核心数据和状态。

功能说明

  • 统计卡片：顶部展示账号总数、关键词总数、在线账号数、今日订单数等关键指标，帮助您快速了解系统概况。
  • 账号状态列表：下方以表格形式展示每个闲鱼账号的详细信息，包括账号名称、商品数量、在线状态、今日消息数、今日订单数等。
  • 快捷操作：每个账号行支持快速查看商品、查看订单、查看回复设置等操作。

使用步骤

  1. 登录系统后默认进入仪表盘页面。
  2. 浏览顶部统计卡片了解整体运行状态。
  3. 查看账号列表，点击操作按钮进行快速导航。

账号管理

管理所有闲鱼Cookie账号，支持添加、删除、启用/禁用、扫码登录等操作。

功能说明

  • 添加账号：支持通过Cookie字符串添加账号，也可通过扫码登录方式添加。
  • 扫码登录：点击"扫码登录"按钮，弹窗显示二维码，使用闲鱼App扫描完成登录，系统自动获取Cookie。
  • 账号列表：展示所有已添加的账号，支持按状态筛选。
  • 账号操作：每个账号可进行启用/禁用、开启/关闭自动确认、设置备注、调整暂停时长、删除等操作。
  • 批量导入：支持批量导入Cookie账号。

使用步骤

  1. 进入"账号管理"页面，点击"添加账号"或"扫码登录"。
  2. 添加成功后，在列表中查看账号信息。
  3. 使用右侧操作按钮管理账号状态和配置。
  4. 定期检查Cookie有效性，及时续期失效的账号。
提示：Cookie过期后需要重新扫码登录，建议定期检查账号状态。

商品管理

管理闲鱼账号发布的商品信息，支持浏览、搜索、筛选和批量操作。

功能说明

  • 商品列表：展示所有商品，包含商品标题、图片、价格、所属账号、状态等信息。
  • 搜索筛选：按关键词、所属账号、商品状态等进行搜索和筛选。
  • 批量操作：支持批量删除、批量导出商品信息。
  • 多规格商品：支持展示和管理多规格商品。

使用步骤

  1. 进入"商品管理"页面，系统自动加载所有商品。
  2. 使用搜索框和筛选条件查找目标商品。
  3. 勾选商品进行批量操作或点击单个商品查看详情。

订单管理

查看和管理闲鱼账号的所有订单，支持按账号筛选和搜索。

功能说明

  • 订单列表：展示所有订单信息，包括订单号、商品名称、金额、买家信息、订单状态、下单时间等。
  • 筛选：按所属账号、订单状态等条件筛选订单。
  • 搜索：支持按订单号或商品关键词搜索。
  • 订单详情：点击查看订单完整信息。

使用步骤

  1. 进入"订单管理"页面，系统自动加载订单数据。
  2. 使用顶部的账号筛选和搜索框查找目标订单。
  3. 点击订单行查看详细内容。

自动回复

配置关键词自动回复规则，当买家发送的消息匹配关键词时自动回复预设内容。

功能说明

  • 按账号配置：为每个闲鱼账号分别配置独立的关键词回复规则。
  • 关键词管理：支持添加、编辑、删除关键词，设置关键词的匹配模式（精确/模糊）。
  • 回复内容：支持文本回复和图片回复，可绑定到指定商品。
  • 默认回复：设置未匹配到关键词时的默认回复内容。
  • AI智能回复：集成AI大模型，开启后可自动生成回复内容（需在系统设置中配置AI参数）。

使用步骤

  1. 进入"自动回复"页面，选择要配置的账号。
  2. 点击"添加关键词"，输入关键词和对应的回复内容。
  3. 可选：绑定到特定商品，设置匹配模式。
  4. 配置默认回复作为兜底回复内容。
  5. 开启自动回复开关，保存配置。
提示：建议为每个账号配置至少3-5个常用关键词，并设置合理的默认回复，以提升回复率。

AI对话历史

查看AI智能回复的对话记录，了解AI与买家的完整交互过程。

功能说明

  • 对话列表：展示所有AI参与的对话，包含买家信息、所属账号、对话时间等。
  • 对话详情：点击查看完整的对话内容，包括买家消息和AI回复。
  • 搜索：支持按关键词搜索对话内容。

使用步骤

  1. 进入"AI对话历史"页面查看所有AI对话记录。
  2. 点击任意对话查看详细的交互内容。
  3. 通过搜索框快速定位特定对话。

指定商品回复

为特定商品配置独立的回复规则，不同商品可以有不同的自动回复内容。

功能说明

  • 商品绑定：选择指定商品并为其配置专属回复内容。
  • 独立规则：每个商品的回复规则独立于全局关键词规则。
  • 优先级：指定商品回复的优先级高于通用关键词回复。

使用步骤

  1. 进入"指定商品回复"页面。
  2. 选择需要配置的账号和商品。
  3. 设置该商品对应的回复内容。
  4. 保存配置，当买家咨询该商品时将自动回复设置的内容。

卡券管理

管理数字卡券（如兑换码、卡密等），支持批量导入和自动发货。

功能说明

  • 卡券类型：支持普通卡密和API类型的卡券。
  • 多规格：支持为卡券设置不同规格（面值、类型等）。
  • 批量导入：支持批量导入卡券数据。
  • 库存管理：自动统计卡券库存数量。
  • 图片上传：支持上传卡券相关图片。

使用步骤

  1. 进入"卡券管理"页面，点击"新建卡券"。
  2. 填写卡券名称、类型、规格等信息。
  3. 批量导入卡券内容（兑换码/卡密）。
  4. 关联到自动发货规则，实现购买后自动发货。

自动发货

配置自动发货规则，买家下单付款后自动发送卡券或虚拟商品。

功能说明

  • 发货规则：创建规则并关联卡券，设置触发条件。
  • 商品关联：将发货规则绑定到指定商品。
  • 自动发送：买家付款后系统自动发送卡券内容到买家聊天窗口。
  • 库存检查：自动检查卡券库存，库存不足时停止自动发货。

使用步骤

  1. 进入"自动发货"页面，点击"新建规则"。
  2. 选择关联的商品和卡券。
  3. 配置触发条件和发货内容。
  4. 启用规则，保存配置。
提示：请确保卡券库存充足，以免自动发货失败。

通知渠道

配置消息通知渠道，支持通过多种方式接收系统通知。

功能说明

  • Webhook：配置Webhook地址，系统将通知发送到指定URL。
  • Bark：支持Bark推送，在iOS设备上接收通知。
  • 其他渠道：支持更多自定义通知方式。

使用步骤

  1. 进入"通知渠道"页面，点击"添加渠道"。
  2. 选择渠道类型，填写配置信息。
  3. 保存并测试通知是否正常送达。

消息通知

为每个账号单独配置消息通知规则，当收到新消息时通过通知渠道发送提醒。

功能说明

  • 按账号配置：为不同的闲鱼账号设置不同的通知策略。
  • 通知规则：选择触发通知的事件类型（新消息、新订单等）。
  • 通知渠道绑定：将通知规则关联到已配置的通知渠道。

使用步骤

  1. 进入"消息通知"页面，选择要配置的账号。
  2. 选择通知触发条件和目标通知渠道。
  3. 保存配置，当触发条件满足时将自动发送通知。

一键转卖

搜索闲鱼平台上的商品，查看商品信息和卖家情况。

功能说明

  • 关键词搜索：输入关键词搜索闲鱼平台商品。
  • 搜索结果：展示商品标题、价格、卖家信息、商品链接等。
  • 筛选排序：支持按价格、销量等维度排序筛选。

使用步骤

  1. 进入"一键转卖"页面。
  2. 输入搜索关键词，点击搜索。
  3. 浏览搜索结果，点击查看商品详情。

系统设置

配置系统的全局参数，包括主题颜色、AI模型、代理设置、注册开关等。

功能说明

  • 主题颜色：调整系统界面主题色。
  • AI设置：配置AI回复的模型名称、API地址、Prompt提示词等参数。
  • 代理设置：配置网络代理，用于访问外部API。
  • 注册开关：控制是否允许新用户通过注册页面自行注册账号。关闭后仅管理员可在用户管理中添加用户。

使用步骤

  1. 进入"系统设置"页面。
  2. 按需调整各项配置参数。
  3. 点击"保存"使配置生效。
提示：修改AI设置后需要重新开启自动回复功能才能生效。

用户管理

管理系统的用户账号，仅管理员可访问。支持添加、编辑、删除用户，以及分配角色。

功能说明

  • 用户列表：以表格形式展示所有注册用户的信息（用户名、邮箱、角色、Cookie数、卡券数、注册时间）。
  • 添加用户：管理员可直接创建新用户，填写用户名、邮箱、密码，并选择角色。
  • 编辑用户：可修改用户的邮箱、重置密码，或变更角色（角色下拉来自"角色配置"中定义的角色）。
  • 删除用户：删除用户及其所有关联数据（Cookie、关键词、卡券等），不可恢复。

使用步骤

  1. 使用管理员账号登录系统。
  2. 进入"用户管理"页面查看所有用户。
  3. 点击"添加用户"创建新账号，或点击编辑/删除按钮管理现有用户。
  4. 分配角色前请先在"角色配置"中定义好角色和对应的权限。

角色配置

管理角色和权限，控制不同用户可以访问的系统功能。仅管理员可访问。

功能说明

  • 角色管理：支持创建自定义角色（如运营、客服等），内置 admin（全部权限）和 user（基础功能）角色不可删除。
  • 权限配置：每个角色可独立勾选 18 项系统功能的访问权限，包括仪表盘、账号管理、商品管理、订单管理、自动回复、AI对话历史、指定商品回复、卡券管理、自动发货、通知渠道、消息通知、一键转卖、系统设置、用户管理、系统日志、数据管理、备份导出、备份导入。
  • 全选/取消：编辑角色时支持一键全选或取消所有权限。
  • 用户关联：在"用户管理"中为用户分配角色后，该用户将根据角色获得对应的功能访问权限。

使用步骤

  1. 点击左侧菜单"角色配置"进入页面。
  2. 点击"添加角色"输入角色名称创建新角色。
  3. 点击角色的"编辑"按钮，在弹出的窗口中勾选该角色应有的权限。
  4. 点击"保存"使配置生效。
  5. 进入"用户管理"页面，编辑用户时从角色下拉中选择刚创建的角色。
提示：admin 角色拥有全部权限且不可修改。user 角色默认拥有除管理员功能外的所有权限。

系统日志

实时查看系统运行日志，支持日志级别筛选和自动刷新。

功能说明

  • 实时日志：实时显示系统运行日志，支持自动滚动到最新。
  • 级别筛选：按INFO、WARN、ERROR等日志级别筛选显示。
  • 自动刷新：开启后日志自动更新，适合监控系统运行状态。
  • 日志搜索：支持关键词搜索日志内容。

使用步骤

  1. 进入"系统日志"页面。
  2. 选择日志级别筛选需要查看的日志。
  3. 开启"自动刷新"实时监控系统运行。
  4. 使用搜索框定位特定日志内容。

数据管理

管理系统的SQLite数据库，支持查看表数据、导出备份、导入恢复。

功能说明

  • 数据表浏览：选择数据库表，查看表中的所有数据记录。
  • 数据导出：将数据库导出为备份文件，支持下载。
  • 数据导入：导入之前备份的数据库文件，恢复数据。
  • 记录统计：显示每个表的记录总数。

使用步骤

  1. 进入"数据管理"页面。
  2. 从下拉列表中选择要查看的数据表。
  3. 浏览表数据或执行导出/导入操作。
  4. 定期备份数据库以防数据丢失。
注意：导入数据会覆盖当前数据库，请提前备份。

如何获取阿奇索 Cookie 和 Authorization？
  1. 打开阿奇索官网
    https://aldsidle.agiso.com/
  2. 登录你的阿奇索账号
    如果还没使用过阿奇索，需要先用闲鱼账号进行产品绑定授权
  3. 打开浏览器开发者工具
    按 F12 键，或右键页面选择"检查"
  4. 找到网络请求
    选择"网络(Network)"标签，在过滤框中输入 GetUserInfo
  5. 刷新页面并复制数据
    刷新网页，点击获取到的请求，在右侧"请求标头"中找到并复制：
    • Cookie 字段的完整内容
    • Authorization 字段的完整内容
